🔍 Reconciliation = check, don't change
Upload a CSV exported from your IT discovery tool to compare against the register. The system reports what is misclassified, undocumented, or has missing fields. Nothing in the register is changed. Use this for periodic audits and CBB compliance checks.
Need to add or update assets instead? Use Bulk Import.

📤 Bulk Import = add or update assets
Upload a CSV that follows the register template to add new assets or update existing ones in a single batch. Each row becomes (or updates) a record in the register. This writes to the database. Use this when on-boarding a new system batch or migrating from a spreadsheet.
Just want to check what is missing or misclassified? Use Reconciliation instead — it is read-only.

Import Guide

The import CSV must include these required columns:

asset_id, system_name, data_category,
data_classification, data_owner

Optional columns: description, business_function, custodian, data_location, who_has_access, access_mechanism, security_controls, encryption_in_transit, encryption_at_rest, retention_period, backup_retention, disposal_method, primary_use, policy_reference, control_mapping, last_review_date, remarks, data_sensitivity, business_criticality, key_risks, inherent_likelihood (1–5), inherent_impact (1–5), residual_likelihood (1–5), residual_impact (1–5), risk_treatment_plan, review_frequency, target_review_date, project_manager, network_ports_protocols

⚠️ If an asset_id already exists, the record will be updated.
